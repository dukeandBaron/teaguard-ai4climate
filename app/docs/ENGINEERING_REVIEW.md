## 已复现问题与修复

| 原行为/结构问题 | 修复 | 关键回归 |
|---|---|---|
| 拼错顶层字段会被忽略 | 明确允许字段集合，未知字段返回错误 | `test_unknown_request_field_is_not_silently_ignored` |
| 前序版本不存在时静默重开 | 明确404、错误类别、独立分析按钮 | `test_missing_previous_version_is_not_silently_reset` |
| 整数观察时间导致AttributeError | 领域输入先校验类型，HTTP返回结构化400 | `test_wrong_soil_time_type_has_a_contract_error` |
| 解释被拒绝前后内容不同但版本号相同 | 领域标识绑定拒绝标志；保存标识覆盖完整结果 | `test_explanation_rejection_changes_domain_identity` |
| 非布尔完成值可能当作真 | 域内与请求边界均严格检查布尔 | `test_feedback_completion_requires_real_boolean` |
| JSON记录直接写文件、并发及完整性边界薄弱 | SQLite事务、完整SHA-256、前序约束和写入锁 | 并发、重开、篡改、孤立前序等测试 |
| 只校验天气CSV，保存预测/评估未一同绑定 | 只读天气库对四份冻结输入校验摘要 | `test_tampered_frozen_prediction_is_rejected` |
| 卡与来源每次读取，来源不完整绑定 | 启动时冻结卡与来源，算法摘要一起绑定 | 领域回归与最终源摘要核对 |
| 历史列表只在当前浏览器 | 服务器记录列表，空白浏览器也能查询 | `test_record_history_is_server_owned`与真实新窗口检查 |
| 反馈等待时条件与导出仍可操作 | 所有记录变更动作统一busy状态 | 已在浏览器复现原问题，修后再验收 |
| 网络失败缺少可判别类别 | 独立API模块、请求编号、超时提示、无自动POST重试 | 三项前端请求契约测试 |
| 单个领域/页面脚本职责过多 | 领域拆为状态、适用性、核查规则和图；前端拆为五模块 | 原行为回归、架构文档与浏览器检查 |

第一批14项工程契约测试在修复前出现13个失败与1个类型崩溃；新增存储模块相关失败表示缺少该能力，并非已证明原实现每项都会发生数据损坏。HTTP与前端请求契约另行先失败后实现。修复中并发检查曾发现SQLite写锁等待问题，已通过单实例写锁和明确事务顺序处理。

## 测试与交付约束

最终结果以`artifacts/ENGINEERING_ACCEPTANCE.json`为准，不能用测试文件存在替代通过记录。需覆盖原79项行为（版本常量与历史查询适配新接口）、新增工程契约、HTTP错误、前端请求、十情境回放及桌面/手机尺寸交互。各阶段前后核对固定源码/数据，以及V1、V2的冻结文件摘要。

AI情境仍只验证软件行为；没有真实团队参与、农业效果或新预测精度。原始三分钟视频和官网附件仍代表历史版本。本轮软件重构不声称新学术方法、农业作用机制或获奖概率。
