# 茶候V0.2：杭州茶园热旱线索解释与巡查助手

对象是茶园巡查与作业安排人员。面对区域天气线索，系统帮助明确先核实什么、为什么，以及补充情境后任务怎样改变。问题定义来自公开研究和场景设计，没有虚构真实农户访谈。

V0.2在本机实现统一自然情境单、五张机制证据卡、地区/作物/环境/处理/终点适用性检查、可拖动关系图、任务去重、模拟反馈版本、Markdown与JSON导出。区域天气和AI现场条件分开标识；未知不补成测量。

文献迁移包括Falcon的观察层次、SpecCLIP的信息特有性、根际研究的物种/处理边界，以及GeoGPT/PEACE的来源与结构化工作流。实际代码为规则、合同和证据图，没有运行这些模型或继承其论文精度。

数据为2015—2025年中心4018天ERA5资料与原V1保存的2025预测。本轮有界扩充至9个返回网格、36162条网格—日期记录，中心值与原资料相同。相邻点原始日最高温相关系数约0.997—0.999；真实地块标签为0，新增数据不等于独立田间样本。

同一份AI天气用于10个逻辑情境、13组输入变体、3档软件组件对照，检查数字不变、引用可解析、适用性、未知、合成来源与去重。40项行为核查已通过；详细自动测试与浏览器记录以本地验收文件为准。这些不是田间或用户效果。

原V1三日最高温MAE约2.848°C、延续基线约3.700°C。原高温区间上界策略137个触发窗口、64命中、73误报、1漏报；没有因本轮新界面或邻域数据而改写。七日参考收支失败结果继续保留，未纳入预测行动。

90天方案仍需合法场景后执行：先核对地点、品种、土层、观测流程与资料时点；再做影子对照，记录遗漏、误报和复核用时；最后评估实际采用原因。没有真实参与者时，继续使用明确AI情境检查软件，农业收益与用户指标保持未测量。

本地启动：python -B nature_server.py --port50114。网页：http://127.0.0.1:50114/ 。运行不需要新增模型训练、GPU、付费API或云服务。当前属于历史/模拟原型，不是实时预警或已上线农业服务。

本材料描述本机V0.2；官网既有附件、视频、公开仓库与正式提交状态没有在本轮自动更新。
