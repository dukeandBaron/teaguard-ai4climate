# V0.3.1 提交候选说明

在已验收V0.3.0基础上做有界发布补丁，原包与回执已按SHA-256核验并保全至独立报告目录。

- 任务绑定相关输入、天气范围、规则与证据摘要。相关依据改变会重新待核查；相同依据或无关遮阴改变不会误清除高温任务的模拟完成。
- 已知土壤状态缺少时间、土层或方法时，优先核对来源。
- 固定AI天气与界面日期一致；无效日历日期或不符情境日期被拒绝。
- 非对象形损坏记录也返回明确完整性错误。
- 连续切换情境时按新的节点集合重新布局，避免保留旧坐标让两个任务自动重叠；同一节点集合内仍支持拖动与重置。
- 新增7项回归，其中修复前4项失败、1项类型崩溃，另外2项为保留行为对照。

本次不新增模型训练、GPU、付费API、真实用户或田间效果。V1原历史数值结果不变。原视频及旧仓库main不自动视为本版。

本候选需具备当前源码验收、≤3分钟实际网页录屏、项目说明、数据与AI声明、90天验证计划、对齐审查和版本清单，才可移交申请人最终确认与平台提交。账号注册、附件上传、同意声明、正式项目提交和报名编号分别记录。
